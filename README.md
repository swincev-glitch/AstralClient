# Astral Client

Лаунчер для Minecraft Bedrock на Android: кнопка запуска, плавающая иконка поверх игры и меню с функциями.

## Что уже есть
- Лаунчер на весь экран (ландшафт), статус игры и разрешений
- Запуск Minecraft (`com.mojang.minecraftpe`)
- Плавающая иконка (перетаскивается), по нажатию открывается меню
- Меню: вкладки Бой / Визуал / Движение / Прочее, переключатели сохраняются
- Сборка APK через GitHub Actions

Переключатели пока ничего не меняют в игре: это следующий этап.

## Как собрать APK через GitHub
1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. Открой вкладку **Actions**: сборка запускается при каждом push в `main` (или кнопкой *Run workflow*).
3. Когда сборка закончится, скачай архив **AstralClient-debug** в разделе *Artifacts* и достань из него `.apk`.
4. Установи APK на телефон (разреши установку из неизвестных источников).

## Первый запуск на телефоне
1. Открой Astral Client и нажми «Запустить Minecraft».
2. Разреши «Показ поверх других приложений».
3. Нажми кнопку ещё раз: запустится Minecraft, поверх него появится иконка.
